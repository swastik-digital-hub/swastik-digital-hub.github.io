📌 Chapter Overview: Units and Measurement

Measurement of physical quantities forms the base of experimental physics. A physical quantity is any characteristic that can be measured and quantified using a standard numerical value and a unit.

1. Fundamental vs. Derived Units

  • Fundamental Units: Independent physical quantities that cannot be defined in terms of other units (e.g., Mass [kg], Length [m], Time [s], Electric Current [A], Temperature [K], Luminous Intensity [cd], Amount of Substance [mol]).
  • Derived Units: Units expressed as combinations of base units (e.g., Force [N = kg·m/s²], Velocity [m/s], Pressure [Pa = N/m²]).

2. Dimensional Analysis Applications

  • Checking the dimensional correctness of equations using the Principle of Homogeneity.
  • Deriving relationships between physical quantities.
  • Converting values between different systems of units (e.g., CGS to SI).

3. Errors in Measurement

Errors represent the difference between the true value and the measured value of a physical quantity. They are categorized into Systematic Errors (instrumental, observational) and Random Errors.
