Python Loops: Zero-to-Hero Masterclass

Welcome! This guide assumes zero prior programming knowledge. By the end of this page, you will understand how loops work, how computers repeat instructions automatically, and how to combine loops inside loops (Nested Loops) with complete confidence.

1. What is a Loop?

Imagine your teacher tells you to write "I will practice Python" 100 times on a piece of paper. Writing it manually takes time and causes fatigue. In programming, a Loop is an automated instruction that tells the computer to run a block of code repeatedly until a condition is met.

Key Concept: Loops eliminate code duplication, make scripts shorter, and handle dynamic amounts of data automatically.

2. The `range()` Function in Detail

Before understanding the for loop, you must master the built-in range() function. It generates a sequence of numbers.

Syntax: range(start, stop, step)

  • start (Optional): The starting integer (default is 0).
  • stop (Required): The upper bound. Important: The loop stops before reaching this number (i.e., stop - 1).
  • step (Optional): The increment or decrement value (default is 1).

Visual Examples:

  • range(5) produces: 0, 1, 2, 3, 4
  • range(2, 6) produces: 2, 3, 4, 5
  • range(1, 10, 2) produces: 1, 3, 5, 7, 9
  • range(5, 0, -1) produces: 5, 4, 3, 2, 1 (Backward count)

3. The `for` Loop

A for loop is used when you know in advance how many times you want to repeat a task, or when you want to iterate over a sequence (such as a string, list, or tuple).

Syntax:

SYNTAX 
for variable in sequence:
    # Code block to execute repeatedly (Indented)

Example 1: Printing numbers 1 to 5

PYTHON 3 
for i in range(1, 6):
    print("Current Count:", i)
Output
Current Count: 1
Current Count: 2
Current Count: 3
Current Count: 4
Current Count: 5

Step-by-Step Logic Trace:

  1. range(1, 6) prepares numbers [1, 2, 3, 4, 5].
  2. Iteration 1: i becomes 1. Prints "Current Count: 1".
  3. Iteration 2: i becomes 2. Prints "Current Count: 2".
  4. This repeats until i reaches 5. Once the range ends, the loop terminates.

4. The `while` Loop

A while loop is a condition-controlled loop. It keeps executing as long as a specified condition remains True. Use it when you don't know the exact number of iterations beforehand.

Syntax:

SYNTAX 
initialization
while condition:
    # Code block
    # Increment / Decrement (Change state)

Example: Countdown Timer

PYTHON 3 
count = 3
while count > 0:
    print("Countdown:", count)
    count -= 1  # Equivalent to: count = count - 1

print("Blast off!")
Output
Countdown: 3
Countdown: 2
Countdown: 1
Blast off!
Warning (Infinite Loops): If you forget to update the variable (e.g., omitting count -= 1), the condition count > 0 will remain True forever, causing an infinite loop that freezes your script!

5. Nested Loops Explained

A Nested Loop is simply a loop placed inside another loop. Think of an analog clock: the minute hand (inner loop) must complete a full 60-minute circle before the hour hand (outer loop) moves forward by 1 step.

5.1 Nested While-For Loop

The outer loop is a while loop, while the inner loop is a for loop. For every single iteration of the outer while loop, the inner for loop runs through its entire sequence.

PYTHON 3 
day = 1
while day <= 2:
    print(f"--- Day {day} Schedule ---")
    for period in ["Math", "Physics", "Computer Science"]:
        print(f"  * Attending {period}")
    day += 1
Output
--- Day 1 Schedule ---
  * Attending Math
  * Attending Physics
  * Attending Computer Science
--- Day 2 Schedule ---
  * Attending Math
  * Attending Physics
  * Attending Computer Science

5.2 Nested For-For Loop

Both outer and inner loops are for loops. This structure is heavily used for 2D grids, matrices, and pattern printing.

PYTHON 3 
# Outer loop controls rows
for row in range(1, 4):
    # Inner loop controls columns
    for col in range(1, 4):
        print(f"({row},{col})", end=" ")
    print()  # New line after inner loop completes
Output
(1,1) (1,2) (1,3)
(2,1) (2,2) (2,3)
(3,1) (3,2) (3,3)

5.3 Nested For-While Loop

The outer loop is a for loop, while the inner loop is a while loop.

PYTHON 3 
for student in range(1, 3):
    print(f"Student #{student} Quiz Phase:")
    attempts = 1
    while attempts <= 2:
        print(f"  - Attempt {attempts} evaluated.")
        attempts += 1
Output
Student #1 Quiz Phase:
  - Attempt 1 evaluated.
  - Attempt 2 evaluated.
Student #2 Quiz Phase:
  - Attempt 1 evaluated.
  - Attempt 2 evaluated.

5.4 Nested While-While Loop

Both outer and inner loops are while loops. You must initialize and increment variables for both levels, making sure to reset the inner loop's variable before entering it again.

PYTHON 3 
i = 1
while i <= 2:
    j = 1  # Reset inner counter for each outer cycle
    while j <= 3:
        print(f"Outer i={i}, Inner j={j}")
        j += 1
    i += 1
Output
Outer i=1, Inner j=1
Outer i=1, Inner j=2
Outer i=1, Inner j=3
Outer i=2, Inner j=1
Outer i=2, Inner j=2
Outer i=2, Inner j=3
