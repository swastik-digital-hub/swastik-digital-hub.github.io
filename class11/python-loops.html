Welcome! This guide assumes zero prior programming knowledge. By the end of this page, you will understand how loops work, how computers repeat instructions automatically, and how to combine loops inside loops (Nested Loops) with complete confidence.

1. What is a Loop?

Imagine your teacher tells you to write "I will practice Python" 100 times on a piece of paper. Writing it manually takes time and causes fatigue. In programming, a Loop is an automated instruction that tells the computer to run a block of code repeatedly until a condition is met.

Key Concept: Loops eliminate code duplication, make scripts shorter, and handle dynamic amounts of data automatically.

2. The `range()` Function in Detail

Before understanding the for loop, you must master the built-in range() function. It generates a sequence of numbers.

Syntax: range(start, stop, step)

  • start (Optional): The starting integer (default is 0).
  • stop (Required): The upper bound. Important: The loop stops before reaching this number (i.e., stop - 1).
  • step (Optional): The increment or decrement value (default is 1).

Visual Examples:

  • range(5) produces: 0, 1, 2, 3, 4
  • range(2, 6) produces: 2, 3, 4, 5
  • range(1, 10, 2) produces: 1, 3, 5, 7, 9
  • range(5, 0, -1) produces: 5, 4, 3, 2, 1 (Backward count)

3. The `for` Loop

A for loop is used when you know in advance how many times you want to repeat a task, or when you want to iterate over a sequence (such as a string, list, or tuple).

Syntax:

SYNTAX 
for variable in sequence:
    # Code block to execute repeatedly (Indented)

Example 1: Printing numbers 1 to 5

PYTHON 3 
for i in range(1, 6):
    print("Current Count:", i)
Output
Current Count: 1
Current Count: 2
Current Count: 3
Current Count: 4
Current Count: 5

Step-by-Step Logic Trace:

  1. range(1, 6) prepares numbers [1, 2, 3, 4, 5].
  2. Iteration 1: i becomes 1. Prints "Current Count: 1".
  3. Iteration 2: i becomes 2. Prints "Current Count: 2".
  4. This repeats until i reaches 5. Once the range ends, the loop terminates.

4. The `while` Loop

A while loop is a condition-controlled loop. It keeps executing as long as a specified condition remains True. Use it when you don't know the exact number of iterations beforehand.

Syntax:

SYNTAX 
initialization
while condition:
    # Code block
    # Increment / Decrement (Change state)

Example: Countdown Timer
