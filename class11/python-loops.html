Python Loops (In-Depth Guide)

Welcome to the Class 11 Computer Science reference guide on iterative control structures (`for` and `while` loops).

1. The `for` Loop

Used for iterating over sequences like lists, strings, or ranges.

PYTHON 3 
# Range loop example
for i in range(1, 4):
    print("Iteration:", i)
Output
Iteration: 1
Iteration: 2
Iteration: 3

2. The `while` Loop

Executes blocks of code repeatedly as long as the condition evaluates to `True`.

PYTHON 3 
count = 3
while count > 0:
    print("Countdown:", count)
    count -= 1
Output
Countdown: 3
Countdown: 2
Countdown: 1
