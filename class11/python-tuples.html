Python Tuples Masterclass

1. Python Tuples

A tuple is an immutable ordered collection of elements.

  • Tuples are similar to lists, but unlike lists, they cannot be changed after their creation.
  • Can hold elements of different data types.
  • These are ordered, heterogeneous and immutable.

2. Creating a Tuple

A tuple is created by placing all the items inside parentheses (), separated by commas. A tuple can have any number of items.

PYTHON 3 
tup = ()
print(tup)

# Using String
tup = ('Swastik', 'Tech')
print(tup)

# Using List
li = [1, 2, 4, 5, 6]
print(tuple(li))

# Using Built-in Function
tup = tuple('Hub')
print(tup)
Output
()
('Swastik', 'Tech')
(1, 2, 4, 5, 6)
('H', 'u', 'b')

3. Creating a Tuple with Mixed Datatypes

Tuples can store elements of different data types, such as integers, strings, lists and dictionaries, within a single structure.

PYTHON 3 
tup = (5, 'Welcome', 7.5, True, [1, 2, 3], {'key': 'value'})
print(tup)
Output
(5, 'Welcome', 7.5, True, [1, 2, 3], {'key': 'value'})

4. Tuple Basic Operations & Accessing

We can access the elements of a tuple by using indexing and slicing, similar to how we access elements in a list. Indexing starts at 0 for the first element and goes up to n-1. Negative indexing starts from -1 for the last element.

PYTHON 3 
tup = tuple("Swastik")
print(tup[0])
print(tup[1:4])  
print(tup[:3])

# Tuple unpacking
tup = ("Swastik", "Tech", "Hub")
a, b, c = tup
print(a)
print(b)
print(c)
Output
S
('w', 'a', 's')
('S', 'w', 'a')
Swastik
Tech
Hub

5. Concatenation of Tuples

Tuples can be concatenated using the + operator. This operation combines two or more tuples to create a new tuple.

Note: Only tuples can be concatenated with tuples. Combining a tuple with other types like lists will raise an error.

PYTHON 3 
tup1 = (0, 1, 2, 3)
tup2 = ('Swastik', 'Tech', 'Hub')
tup3 = tup1 + tup2
print(tup3)
Output
(0, 1, 2, 3, 'Swastik', 'Tech', 'Hub')

6. Slicing of Tuple

Slicing a tuple means creating a new tuple from a subset of elements. The syntax is tuple[start:stop:step].

Note: Negative increment values can be used to reverse tuples. [:] returns all elements, and [::-1] reverses the sequence.

PYTHON 3 
tup = tuple('SWASTIKHUB')
print(tup[1:])
print(tup[::-1])
print(tup[4:9])
Output
('W', 'A', 'S', 'T', 'I', 'K', 'H', 'U', 'B')
('B', 'U', 'H', 'K', 'I', 'T', 'S', 'A', 'W', 'S')
('T', 'I', 'K', 'H', 'U')

7. Deleting a Tuple

Since tuples are immutable, we cannot delete individual elements. However, we can delete an entire tuple using the del statement. Printing after deletion results in a NameError.

PYTHON 3 
tup = (0, 1, 2, 3, 4)
del tup
print(tup)
Output
ERROR!
Traceback (most recent call last):
  File "<main.py>", line 6, in <module>
NameError: name 'tup' is not defined

8. Tuple Unpacking with Asterisk (*)

The * operator is used in tuple unpacking to grab multiple items into a list. This is useful to extract specific elements and collect the rest together[cite: 4].

PYTHON 3 
tup = (1, 2, 3, 4, 5)
a, *b, c = tup
print(a) 
print(b) 
print(c)
Output
1
[2, 3, 4]
5

Explanation: a gets the first item, c gets the last item, and *b collects everything in between into a list[cite: 4].

Property Python List Python Tuple
