Python Lists Masterclass

A list is a built-in data structure used to store an ordered collection of items. They are dynamic, resizable, and capable of storing multiple data types.

  • List elements can be changed, updated, added, or removed after the list is created.
  • Elements maintain the order in which they are inserted.
  • Elements are accessed using their position, starting from index 0.

1. Creating a List

Lists can be created in several ways, such as using square brackets [], the list() constructor, or by repeating elements.

1. Using Square Brackets:

PYTHON 3
a = [1, 2, 3]
print(a)

b = ["apple", "banana"]
print(b)
Output
[1, 2, 3]
['apple', 'banana']

2. Using list() Constructor:

PYTHON 3
a = list((1, 2, 3, 'apple', 4.5))  
print(a)

b = list("GFG")
print(b)
Output
[1, 2, 3, 'apple', 4.5]
['G', 'F', 'G']

3. Creating List with Repeated Elements:

PYTHON 3
a = [2] * 5
b = [0] * 7

print(a)
print(b)
Output
[2, 2, 2, 2, 2]
[0, 0, 0, 0, 0, 0, 0]

2. Internal Representation of Lists

PYTHON 3
a = [1, 2, 2, "Python"]
print(a[0])    # index-based
print(a)
Output
1
[1, 2, 2, 'Python']

3. Accessing Elements

PYTHON 3
a = [10, 20, 30]
print(a[0])
print(a[-1])
Output
10
30

4. Adding Elements

1. append():

PYTHON 3
a = [1, 2]
a.append(3)
print(a)
Output
[1, 2, 3]

2. insert():

PYTHON 3
a = [1, 3]
a.insert(1, 2)
print(a)
Output
[1, 2, 3]

3. extend():

PYTHON 3
a = [1, 2]
a.extend([3, 4])
print(a)
Output
[1, 2, 3, 4]

5. Updating Elements

PYTHON 3
a = [10, 20, 30, 40, 50]
a[1] = 25 
print(a)
Output
[10, 25, 30, 40, 50]

6. Removing Elements

1. remove():

PYTHON 3
a = [1, 2, 3]
a.remove(2)
print(a)
Output
[1, 3]

2. pop():

PYTHON 3
a = [1, 2, 3]
a.pop()
print(a)
Output
[1, 2]

3. del statement:

PYTHON 3
a = [1, 2, 3]
del a[1]
print(a)
Output
[1, 3]

4. clear():

PYTHON 3
a = [1, 2, 3]
a.clear()
print(a)
Output
[]

7. Iterating Over Lists

PYTHON 3
a = ['apple', 'banana', 'cherry']
for item in a:
    print(item)
Output
apple
banana
cherry

8. Nested Lists

PYTHON 3
a = [[1, 2], [3, 4]]
print(a[0])
print(a[1][0])
Output
[1, 2]
3
