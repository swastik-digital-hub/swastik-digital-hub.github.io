Python Lists, Tuples & Loops

Welcome to Class 11 Computer Science revision notes. This comprehensive guide covers Python Lists, Tuples, and control structures like Loops.

1. Python Lists in Detail

A list is a sequence of comma-separated items enclosed within square brackets [ ]. Lists are mutable, meaning elements can be modified, added, or removed after creation.

Key List Operations & Methods:

  • append(x): Adds an item at the end of the list.
  • insert(i, x): Inserts an item at index i.
  • remove(x): Removes the first occurrence of item x.
  • pop([i]): Removes and returns the item at index i.

Example Code: Advanced List Manipulation

PYTHON 3 
# Initializing a list
my_list = [10, 20, 30, 40, 50]

# Slicing lists
print("Elements from index 1 to 3:", my_list[1:4])

# Modifying elements
my_list[0] = 99
print("After Modification:", my_list)

# Using built-in methods
my_list.append(60)
my_list.pop(2) # Removes element at index 2 (30)
print("Final List:", my_list)
Output
Elements from index 1 to 3: [20, 30, 40]
After Modification: [99, 20, 30, 40, 50]
Final List: [99, 20, 40, 50, 60]

2. Python Tuples in Detail

A tuple is an ordered sequence of elements separated by commas and enclosed in parentheses ( ). Unlike lists, tuples are immutable—they cannot be changed once defined.

Example Code: Tuple Packing and Unpacking

PYTHON 3 
# Tuple Packing
student_info = ("Swastik", 16, "Class 11")

# Tuple Unpacking
name, age, grade = student_info
print("Name:", name)
print("Age:", age)
print("Grade:", grade)

# Tuple functions: count() and index()
numbers = (1, 2, 3, 2, 4, 2)
print("Count of 2:", numbers.count(2))
print("Index of first 4:", numbers.index(4))
Output
Name: Swastik
Age: 16
Grade: Class 11
Count of 2: 3
Index of first 4: 4

3. Python Loops (Iterative Statements)

Loops are used to execute a block of code repeatedly until a specific condition is met or through a sequence of items. Python provides two main types of loops: for loop and while loop.

A. The `for` Loop

A for loop is used for iterating over a sequence (such as a list, tuple, string, or range).

PYTHON 3 
# Iterating using range()
print("Range loop:")
for i in range(1, 4):
    print(i, end=" ")

# Iterating through a list
print("\nList iteration:")
fruits = ["Apple", "Banana", "Mango"]
for fruit in fruits:
    print(fruit)
Output
Range loop:
1 2 3
List iteration:
Apple
Banana
Mango

B. The `while` Loop

A while loop executes statements as long as the given condition remains True.

PYTHON 3 
# Countdown using while loop
count = 3
while count > 0:
    print("Countdown:", count)
    count -= 1
print("Liftoff!")
Output
Countdown: 3
Countdown: 2
Countdown: 1
Liftoff!

C. Loop Control Statements: `break` and `continue`

  • break: Terminates the loop entirely when a condition is met.
  • continue: Skips the current iteration and moves to the next one.
PYTHON 3 
# Using break and continue
for num in range(1, 6):
    if num == 3:
        continue # Skips printing 3
    if num == 5:
        break    # Stops loop at 5
    print(num, end=" ")
Output
1 2 4
