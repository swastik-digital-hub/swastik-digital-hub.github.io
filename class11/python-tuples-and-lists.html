Python Lists and Tuples

Welcome to Class 11 Computer Science revision notes. In this chapter, we explore two core collection data types in Python: Lists and Tuples.

1. Python Lists

A list is a mutable (modifiable) ordered sequence of elements. Elements can be of any data type and are enclosed in square brackets [].

Example: Creating and Modifying a List

# Creating a list of marks
marks = [85, 90, 78, 92, 88]

# Modifying an element (Lists are mutable)
marks[2] = 80
print("Updated Marks:", marks)

# Adding an element using append()
marks.append(95)
print("After Append:", marks)

2. Python Tuples

A tuple is an immutable (unchangeable) ordered sequence of elements enclosed in parentheses (). Once created, its values cannot be modified.

Example: Creating a Tuple

# Creating a tuple of coordinates
point = (10, 20)

print("X coordinate:", point[0])
print("Y coordinate:", point[1])

# Attempting to change a value will result in a TypeError:
# point[0] = 15 (Error!)

3. Key Differences: List vs Tuple

Feature Python List Python Tuple
Mutability Mutable (Can be changed) Immutable (Cannot be changed)
Syntax Square brackets [ ] Parentheses ( )
Performance Slightly slower due to dynamic sizing Faster execution speed
Built-in Methods Many methods (append(), remove(), etc.) Fewer methods (count(), index())
