Python Lists & Tuples (In-Depth Guide)

Welcome to the Class 11 Computer Science reference guide on compound data types. Explore Python Lists and Tuples in detail below.

1. Python Lists

A list is a mutable, ordered sequence enclosed in square brackets [ ].

PYTHON 3 
# Creating and modifying lists
my_list = [10, 20, 30, 40]
my_list.append(50)
my_list[0] = 99
print("Updated List:", my_list)
Output
Updated List: [99, 20, 30, 40, 50]

2. Python Tuples

A tuple is an immutable, ordered sequence enclosed in parentheses ( ).

PYTHON 3 
# Tuples are immutable
point = (10, 20)
print("X:", point[0], "Y:", point[1])
# point[0] = 15  # Raises TypeError!
Output
X: 10 Y: 20

3. List vs Tuple Comparison

Feature List Tuple
Mutability Mutable (Modifiable) Immutable (Unchangeable)
Syntax Square brackets [ ] Parentheses ( )
