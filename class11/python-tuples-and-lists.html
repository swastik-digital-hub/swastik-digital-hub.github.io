Python Lists and Tuples: Zero-to-Hero Masterclass

Welcome! In Python, when you need to store multiple items inside a single variable, you use compound data structures like Lists or Tuples.

1. Python Lists (Mutable Sequences)

A list is a sequence of values separated by commas and wrapped in square brackets [ ]. Lists are Mutable, meaning you can edit, add, or delete elements after creating the list.

PYTHON 3 
# Creating a list with multiple data types
my_list = [10, "Swastik", 95.5, True]
print("Original List:", my_list)

# Modifying a list element (Mutability in action)
my_list[0] = 100
print("Modified List:", my_list)
Output
Original List: [10, 'Swastik', 95.5, True]
Modified List: [100, 'Swastik', 95.5, True]

1.1 Indexing & Slicing Demystified

Positive Indexing: Starts at 0 from left to right.
Negative Indexing: Starts at -1 from right to left.

PYTHON 3 
fruits = ["Apple", "Banana", "Cherry", "Date", "Elderberry"]

# Indexing
print("First fruit [0]:", fruits[0])
print("Last fruit [-1]:", fruits[-1])

# Slicing syntax: list[start : stop : step]
print("Slice [1:4]:", fruits[1:4])
print("Reverse list [::-1]:", fruits[::-1])
Output
First fruit [0]: Apple
Last fruit [-1]: Elderberry
Slice [1:4]: ['Banana', 'Cherry', 'Date']
Reverse list [::-1]: ['Elderberry', 'Date', 'Cherry', 'Banana', 'Apple']

1.2 Essential Built-in List Methods

  • append(x): Adds item x to the end.
  • insert(index, x): Inserts item x at position index.
  • remove(x): Deletes the first occurrence of x.
  • pop(index): Removes and returns the item at position index.
  • sort(): Rearranges the list in ascending order.
PYTHON 3 
nums = [40, 10, 30, 20]
nums.append(50)
nums.insert(1, 15)
print("After append & insert:", nums)

nums.sort()
print("Sorted List:", nums)
Output
After append & insert: [40, 15, 10, 30, 20, 50]
Sorted List: [10, 15, 20, 30, 40, 50]

2. Python Tuples (Immutable Sequences)

A tuple is a sequence wrapped in parentheses ( ). Tuples are Immutable, meaning once created, elements cannot be altered or deleted.

2.1 Single Element Tuple Rule

To create a tuple with only 1 item, you must place a trailing comma after the element. Otherwise, Python treats it as a regular parenthesis grouping expression.

PYTHON 3 
# Incorrect single item tuple
not_a_tuple = (5)
print("Type of (5):", type(not_a_tuple))

# Correct single item tuple
correct_tuple = (5,)
print("Type of (5,):", type(correct_tuple))
Output
Type of (5): <class 'int'>
Type of (5,): <class 'tuple'>

2.2 Tuple Packing and Unpacking

PYTHON 3 
# Packing
student_data = ("Swastik", 16, "Class 11")

# Unpacking
name, age, grade = student_data
print(f"Name: {name}, Age: {age}, Grade: {grade}")
Output
Name: Swastik, Age: 16, Grade: Class 11

3. Key Differences: List vs Tuple

Property Python List Python Tuple
Mutability Mutable (Can be edited) Immutable (Cannot be edited)
Syntax Square brackets [ ] Parentheses ( )
Performance Slower iteration Faster execution & memory efficient
